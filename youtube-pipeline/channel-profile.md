# Channel Profile — History_Bites (@Historybites_mini)

Paste-ready copy for YouTube Studio → Edit channel. Kept in the repo so the
public-facing identity stays consistent with style-guide.md.

## Description (paste into the Description field)

```
Small stories. Big history.

History_Bites serves micro-history in bite-sized explainers: the button that
may have beaten Napoleon, the map error that became a real town, the winter
London held a fair on the Thames. One specific true thing per video — and why
it mattered.

New long-form explainers every Tuesday and Saturday. Shorts through the week.

When historians disagree, we say so. When it's legend, we label it. No
"hidden truths," no fake mysteries — the real records are stranger anyway.

Some video descriptions contain affiliate links; they're always disclosed.
```

## Channel art notes (from style-guide.md)

- Avatar + banner: parchment/ink neutrals, one accent color, simple wordmark.
  No AI-slop collages; a clean "HB" monogram or a single engraved-style object
  (hourglass, compass rose) reads well at 88px.
- Banner tagline: "Small stories. Big history."

## Reminder before first upload

- YouTube Studio → Settings → Channel → ensure the channel is set as
  **not made for kids** by default (the pipeline also sets it per-video).
- Set channel keywords: history, micro history, explainer, forgotten history,
  history documentary, myths debunked.
