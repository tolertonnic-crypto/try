Can you prove your agent acted within its mandate?

Autonomous agents cannot currently prove they reasoned within their mandate. Not because of bad logs — because of a structural gap in accountability that no production system closes. This is the reference architecture for that gap, and a free tool to score your own deployment against it.

Perfect logs are not enough

Accountability has four independent components. Most deployments have two. The third — an observer that can catch a deviation the agent itself would call compliant — is unsolved industry-wide, and it is where deployment liability concentrates.

ComponentThe question it answersIndustry status
1 · Signed intentWhat was the agent told?Partially solved
2 · Custody chainWhat did the agent do?Largely solved
3 · External witnessDid it reason within mandate?Architecturally open
4 · Verification attestationDid the outcome match the mandate?Partly solved

The falsification test

One cheap question separates a genuine external witness from a sophisticated log. Run it on any vendor claiming external or reasoning-level verification.

A valid external witness must be able to detect a deviation that the agent itself would classify as compliant. If it only catches what the agent could have caught, it is a log, not a witness.

EigenLayer AVS attestation, Chainlink DECO, organizational audit teams, same-family cross-agent verification, and formal constraint checking all fail it — each attests to the wrong layer. See the worked examples →
